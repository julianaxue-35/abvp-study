Non-Surgical Sterilization

Non-Surgical Sterilization · Companion Animal Homelessness (12%) · Shelter Medicine

High-yield cheatsheet — HPG-axis interference levels, product regulatory status, four contraceptive modalities, population thresholds, ID marking. Added / clarified points marked +.

The HPG Axis: Three-Level Architecture

  • Pulsatile GnRH (gonadotropin-releasing hormone) from hypothalamus → pituitary FSH / LH (follicle-stimulating / luteinising hormone) → gonadal steroids; continuous, non-pulsatile stimulation desensitises receptors+
  • Negative feedback — gonadal androgens / estrogens / progesterone suppress hypothalamus & pituitary
  • Axis is highly conserved across mammals → GnRH-targeting agents get broad cross-species efficacy
  • Gonadal targets = zona pellucida (on ovulated egg, for sperm recognition) + thecal support cells of ovary / testis

Three Levels of HPG Axis Interference

  • Level 1 — hypothalamus / ant. pituitary: GnRH agonists (deslorelin, gonazon) + progestins / androgens block GnRH signalling & gonadotropin release
  • Level 2 — gonads: chemical castrants (zinc gluconate, CaCl₂) destroy testicular tissue directly; GnRH vaccine binds GnRH post-hypothalamus, pre-BBB → halts ovulation + spermatogenesis
  • Level 3 — downstream / oocyte: PZP vaccine hits zona pellucida → blocks sperm recognition; spares HPG axis → fewer hormonal / behavioural effects

Population Modeling: The 40 to 50% Rule

  • 40–50% treated per 6-month interval AND a near-closed population (limited immigration / emigration) — both conditions required+
  • Evidence base = feral cat colonies (modelling of TNR-style non-surgical contraception)
  • Ideal-contraceptive criteria differ by setting: feral = permanent / lifetime, field-deliverable by a non-vet; owned = shorter-term, reversibility a feature not a flaw
Trap 40–50% threshold ALONE fails in an open population — treated animals are continuously replaced by intact immigrants, negating any population effect.

Approved & Available Products

  • Zinc gluconate = Neutersol / Zeuterin / Esterilsol — intratesticular injection, dogs (Neutersol FDA-approved 2003, off US market 2005)+
  • Esterilsol / Zeuterine = identical zinc-gluconate formulation, sold Mexico / Central / South America (not US)
  • Infertile = zinc gluconate + DMSO (vehicle) + arginine (neutraliser) — Brazil, launched 2009; same testicular-sclerosis mechanism as Neutersol+
  • Suprelorin (deslorelin) — GnRH superagonist, reversible; first available Australia 2004
  • Gonazon — EU-approved 2006 (1-yr reversible, female dogs) but never commercially released ("approved" ≠ "available")
  • ALL approved sterilants labelled dogs only — cat use is off-label

Chemical Contraceptives

  • SC misdirection (subcutaneous) of zinc gluconate → necrotising reaction / scrotal ulcers; chemical restraint advised+
  • Zinc gluconate intratesticular → testicular sclerosis → permanent azoospermia / oligospermia + partial ↓testosterone; ~99% effective; testes stay in situ → ID mark required
  • Calcium chloride — must be in a lipid vehicle (alcohol / lidocaine) for deep necrosis without extreme pain & scrotal sloughing
  • Cats worse than dogs — higher rate of severe inflammation, scrotal necrosis, self-mutilation (reluctance = surgery faster + worse reactions, both)

Immunocontraceptives

  • PZP vaccine (porcine zona pellucida) — anti-zona antibody, females only, downstream (spares HPG); completely ineffective in queens (abnormal estrus + injection reactions); poor cross-species; expensive
  • GnRH vaccine — anti-GnRH antibody pre-BBB → shuts down ovulation + spermatogenesis; both sexes; works in horses / deer / elephants with annual booster (sterile abscess risk)
  • Canine GnRH-vaccine failure — neither safe nor effective; severe injection reactions, no drop in sperm density / morphology

Hormonal Contraceptives

  • GnRH agonists e.g. deslorelin (Suprelorin) — reversible; "flare" 1–3 wks (transient fertile estrus / ↑libido) before suppression+
  • Mechanism: continuous non-pulsatile GnRH stimulation → downregulates & desensitises pituitary receptors → ↓LH / FSH; broad cross-species
  • Historical (1970s): progestin megestrol acetate + androgen mibolerone — frequent oral dosing; AEs pyometra, mammary hyperplasia / carcinoma, DM, adrenal suppression → abandoned
  • Feralstat = low-dose megestrol in cat food for ferals; not recommended (no control over non-target consumption)

Identification Marking

  • Ear-tipping CONTRAINDICATED — permanent mark for a temporary contraceptive; use microchip / tattoo / metal ear band instead+
  • Acceptable marks: microchip; tattoo on caudolateral ventral abdomen or inner pinna; small metal ear band
  • Ideal feral marker: minimally invasive, field-applicable, visible at distance, lasts ~ contraceptive duration OR encodes type + date
  • Why ear-tip fails: signals permanent sterility; on a temporary implant the animal regains fertility but stays flagged → field teams skip re-treatment → wrecks population data

Board-Critical Gaps & Exam Traps

  • No approved permanent non-surgical option for female dogs or cats yet+
  • Deslorelin does NOT suppress immediately — flare = 1–3 wk transient ↑LH / FSH / steroids first; female fertile estrus, male ↑libido / aggression; keep from intact males in window
  • Experimental, no canine data: IUD (dogspiral) — cervix anatomy concerns; gene delivery — AAV anti-GnRH wanes <1 mo, MIS lasts only months in cats
Trap An option claiming deslorelin causes "immediate, profound downregulation within hours" is wrong — fertility is transiently enhanced for 1–3 wks before suppression.
