Record Keeping

Record Keeping · Shelter Management (18%) · Shelter Medicine

One-page cheatsheet — Record Keeping subdomain (verified vs ASV Standards of Care 2022). Added / clarified points marked +.

The Digital Standard

  • Standard, not a preference — shelter-specific software → preferred; structured spreadsheets acceptable; paper-only (ledgers, cage cards, whiteboards) non-compliant.+
  • Shelter-specific edge — built-in intake categories, outcome types, Asilomar classes, housing-by-time tracking
  • Also non-compliant — verbal tradition among senior staff as the primary record system
  • Platform-agnostic — any digital system compliant if it supports both individual records + population reports
Trap The line is digital vs paper, NOT shelter-specific vs generic. A well-structured spreadsheet is compliant; any paper system is not.

Why digital over paper?

  • Digital wins on — instant individual lookup, automated population reports, and instant housing-by-time reports for outbreak contact tracing / ALOS (average length of stay) aggregation.+
  • Outbreak tracing — housing-by-time report for any date range vs hand-reconstructing cage logs
  • Regulatory exports — standardized SAC / state / municipal reports; paper = manual, high error
  • Goal tracking — real-time dashboard vs manual comparison
  • Individual lookup — instant search by ID / name / any field vs misfiled physical files

What shelter software manages

  • Three operational domains — resources, schedules, and shelter processes.+
  • Resources — staffing hours, vet supplies, surgical-suite slots, transport, funding
  • Schedules — cleaning rotations, med rounds, surgical lists, adoption slots, foster check-ins
  • Processes — intake, holding-period tracking, fast/slow-track pathway, outcome, transfer
  • Paper can't — aggregate data, generate population reports, or track goals in real time

Dual Reporting Requirement

  • Two required outputs — (1) individual animal records + (2) basic population-level reports; a system that does only one is deficient.+
  • Deficient both ways — individual-only fails; summary-only fails; dual capability is the requirement
  • Generic software — retail inventory tools can't meet the dual-reporting mandate
  • Retrieval cue — pull Dog #448's vaccine dates = individual; pull feline Q2 LRR vs last year = population

Comparing the two report types

  • Individual record (one animal — intake, meds, housing, outcome)
  • Population report (cohort — intakes, ALOS, LRR (live release rate), euthanasia %)
  • Timing — individual updated continuously; population generated on demand per period
  • Audience — individual = vet/care staff, case managers; population = Board, funders, municipal oversight, public
  • Content — individual: intake, description, treatments, housing, outcome; population: totals, ALOS, LRR, species %, euthanasia %, outbreak patterns

Population-level reports in practice

  • Intake report — by type (stray, OS, OIE, transfer, return, born-in-care) + species
  • LRR report — live outcomes % of intakes, broken down by Asilomar category → SAC
  • ALOS by cohort — species, age, intake type, track
  • Disease surveillance — URI / parvo / ringworm incidence across population over time
  • Goal-progress report — current metrics vs stated strategic-plan targets
  • Cadence — generated on demand per reporting period (weekly / monthly / quarterly / annually)

Goal Assessment and Reporting

  • Active mandate — the system must allow regular assessment and reporting of organizational goals and activities (active, not passive).+
  • Drives decisions — justify funding allocations, adjust C4C thresholds on real-time data
  • Passive data fails — data that can't be interrogated can't drive improvement
  • Resources as an indirect goal tool — surgical-suite 3-wk wait = bottleneck → extends LOS, suppresses LRR; system flags it, leadership acts
  • Grant reporting — funders want resource-deployment accounting; digital delivers reliably, paper can't
  • Board budget case — annual aggregate intake / outcome / LRR data justifies the ask

How goal assessment connects to strategic planning

  • Population, not individual — goal assessment needs population-level reports; strategic plans reviewed quarterly against stated targets.+
  • Sets measurable targets — e.g. reduce feline ALOS 10% over Q3; system reports whether met
  • Inert without it — no regular assessment → strategic plan is a dead document, not a management tool
  • Quarterly loop — plan target → population report → compare → adjust capacity/programs
Trap Evaluating a goal (“did feline LRR improve?”) needs population-level reports, not individual records. Individual = one cat; population = the whole cohort.

What “regular assessment” means in practice

  • Cadence (daily census / C4C (capacity for care) → weekly → monthly → quarterly → annual)
  • Daily / weekly — census vs C4C, admissions/discharges, housing utilization; ALOS trends, medical caseload+, foster numbers
  • Monthly — LRR, intake by type, euthanasia by Asilomar category, return rate
  • Quarterly / annual — plan progress vs targets, all metrics vs stated targets (Board + ED); SAC submission, full-year benchmarking, trend analysis+ + budget planning (annual)
  • Who reviews — daily: ops manager/director; monthly: leadership; quarterly+: Board + ED
